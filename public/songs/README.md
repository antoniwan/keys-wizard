# Bundled songs

We have permission to share each file in this folder. The rule, and the steps to add a song, are in [AGENTS.md](../../AGENTS.md).

The command `npm run songs` builds these files from the sources in `songs-src/`. Do not change these files by hand.

The arrangements have the [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) license. You can use them for any purpose.

| File | Piece | Where the music comes from |
| --- | --- | --- |
| `twinkle.gp` | Twinkle, Twinkle, Little Star | Traditional melody, public domain. Arrangement written for this repo. |
| `ode-to-joy.gp` | Ode to Joy | Beethoven, Symphony No. 9 (1824), public domain. Arrangement written for this repo. |
| `minuet-in-g.gp` | Minuet in G, BWV Anh. 114 | Christian Petzold, from the Notebook for Anna Magdalena Bach (1725), public domain. Arrangement written for this repo. |
| `fur-elise.gp` | Für Elise (opening) | Beethoven, WoO 59 (1810), public domain. Arrangement written for this repo. |
| `tower-stairs.gp` | Tower Stairs | Original guitar étude written for this repo. |
